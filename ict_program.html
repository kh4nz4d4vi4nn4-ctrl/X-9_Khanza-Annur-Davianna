Information and Communication Technology Class Program

Introduction

The ICT Program is a Class program that teaches students about technology and computer skills. students learn how technology can be used for learning and solving problems.

In this program, students learn different progamming and computer technologies. These skils can helps students prepare for the future.

Learning Topics

  • HTML
  • CSS
  • JavaScript
  • PHP
  • MySQL

Learning Roadmap

  1. Learn HTML
  2. Learn CSS
  3. Learn JavaScript
  4. Learn PHP
  5. Learn MySQL

Technology Definitions

HTML
HTML is used to create the structure of a webpage.
CSS
CSS is used to design and style a webpage.
JavaScript
JavaScript is used to make webpage interactive.
PHP
PHP is a programming language used for web development.
MySQL
MySQL is used to store and manage data.
